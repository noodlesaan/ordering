# Noodlesaan Ordering System

## Local Development

To test this project locally, you can use [Ghps](https://github.com/sepandhaghighi/ghps) a minimal GitHub Pages simulator written in pure Python.

Install Ghps:

```console
pip install "ghps>=0.8"
```

Run:

```console
ghps
```

Then open your browser and visit:

```console
http://localhost:6001
```

## Dependencies

- [Tailwind CSS](https://tailwindcss.com/) v3.4.19
- [Vazirmatn Font](https://fonts.google.com/specimen/Vazirmatn)
